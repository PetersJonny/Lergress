# Lergress

## 🎯 Objective

This repository documents my learning journey through the **Alura Java Back-End Developer track**. The goal is to apply and document the knowledge acquired from each course.

## 🛠️ Skills & Concepts to be Acquired

By the end of this track, I will have developed the technical competencies to work as a complete Java Back-End Developer, mastering:

### Java Fundamentals & Core Concepts
* **Java Language:** Mastery of syntax, data structures (lists, collections), and the pillars of **Object-Oriented Programming** (Encapsulation, Inheritance, Polymorphism).
* **Advanced Features:** Exception handling, threads, memory management, and the use of Reflection.
* **Best Practices:** Applying refactoring, design patterns, and writing clean code.

### APIs and Spring Framework
* **Spring Framework:** Deep knowledge of the Spring ecosystem, especially **Spring Boot**.
* **API Development:** Building robust RESTful APIs, following best practices and conventions.
* **Documentation & Testing:** Ability to document APIs (e.g., OpenAPI/Swagger), test (TDD, BDD with Cucumber), and prepare applications for deployment.

### Data Persistence
* **Databases:** Connecting Java applications to relational databases using **JDBC**.
* **Object-Relational Mapping (ORM):** Using **JPA** and **Hibernate** for productive data persistence, along with Spring Data JPA to simplify queries.

### Security
* **Spring Security:** Implementing security in web applications and APIs, including:
    * Role-based authentication and authorization.
    * Login via OIDC providers (Google, GitHub) and Two-Factor Authentication (2FA).
    * Protection against common attacks (SQL Injection, XSS, CSRF, etc.).

### Architecture and Microservices
* **Architectural Patterns:** Modeling applications with **Domain-Driven Design (DDD)** and **Clean Architecture**.
* **Microservices:** Implementing a microservice architecture with Spring, understanding communication, scalability, and resilience.
* **Messaging:** Using messaging systems like **RabbitMQ** for asynchronous communication.

### DevOps and Cloud
* **Infrastructure as Code (IaC):** Provisioning cloud infrastructure (AWS) using **AWS CDK**.
* **Deployment:** Deploying Java applications to the cloud.
* **Build:** Managing dependencies and building projects with **Maven**.

### Modern Ecosystem
* **Reactive Programming:** Developing reactive applications with **Spring WebFlux**.
* **Cloud Native:** Building cloud-optimized applications with **Quarkus**.
* **Batch Processing:** Using **Spring Batch** for processing large volumes of data.
